# sswrap

Premium scroll-story landing for automotive film installation.

## Stack

- Angular 17 standalone
- Three.js procedural 3D scene
- SCSS responsive layout

## Scroll Flow

1. Film roll with placeholder brand
2. Film opens while scrolling
3. A piece is cut from the roll
4. New SUV-style 3D car appears
5. Camera zooms into the windshield
6. Film is applied on the glass

## Run

```bash
npm install
npm start
```

Then open `http://localhost:4200`.
